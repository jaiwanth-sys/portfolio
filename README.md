# Jaiwanth S. — Developer Portfolio Website

A modern, high-performance, and responsive portfolio website designed for **Jaiwanth S.** (B.Tech CSE - AI & ML undergraduate at Karunya Institute of Technology and Sciences).

## 🚀 Live Features
- **Cyber-Glassmorphic UI**: Sleek dark and light theme toggle with local storage persistence.
- **Dynamic Typewriter & Particle Background**: Interactive constellation particle canvas with dynamic roles.
- **Project Showcase & Deep-Dive Modals**: Filterable project gallery with technical modal popups.
- **Skills Matrix & Verified Badges**: Organized skill bars and credential cards.
- **Interactive Resume Modal**: In-browser printable/downloadable resume view matching official resume format.
- **Interactive Contact Suite**: 1-click clipboard copy for email & phone number, plus a functional mailto message dispatcher.

## 🛠️ How to Open & Run Locally
1. Simply double-click `index.html` to open it in Google Chrome, Microsoft Edge, Firefox, or any modern web browser.
2. Or serve it using a lightweight local web server:
   ```bash
   # Using Python 3
   python -m http.server 3000

   # Using Node npx serve
   npx serve .
   ```
3. Open `http://localhost:3000` in your browser.

## 🌐 Free 1-Click Deployment Options

### Option 1: GitHub Pages
1. Push this repository to your GitHub account: `https://github.com/jaiwanth-sys/portfolio`.
2. Navigate to **Settings** > **Pages**.
3. Under **Branch**, select `main` (root) and click **Save**.
4. Your site will be live at `https://jaiwanth-sys.github.io/portfolio/` in less than 2 minutes!

### Option 2: Vercel / Netlify
1. Connect your GitHub repository to [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
2. Click **Deploy**. No build commands required (static HTML/CSS/JS).
